프로그램 밖의 AI · 정보 · 기능을 연결해 쓰는 구조

필요한 기능은 외부 서비스와 연결해 확장합니다

✳어떻게 해야 하나?
  1. 앱에 필요한 외부 능력(AI 문법 질문, CNN 기사 수집 등)을 탐색한다.
  2. 해당 기능을 제공하는 외부 서비스에서 API Key를 발급받는다.
  3. AI에게 API Key를 전달하여 외부 기능의 연동을 지시한다.
✳무엇이 가능해지나?
  • —미리 넣어 둔 설명과 예문만 표시
  • —뉴스 · 정보가 최신 내용으로 바뀌지 않음
  • —프로그램 안에 만든 기능만 사용 가능
  • →사용자 질문에 AI가 실시간으로 답변
  • →최신 정보를 자동으로 불러와 활용
